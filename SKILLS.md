# Starlight Agentic OS — Skill Routing

Use the smallest capability set that matches the work:

| Work | Required route |
| --- | --- |
| Repository, branch, PR, or release state | GitHub |
| Pack lifecycle or certification | This repository's validators and runbook |
| CI failure | GitHub CI investigation workflow |
| UI/UX, imagery, motion, or public web release | `starlight-design-intelligence` |
| Product or protocol canon | `Starlight-Intelligence-System` |
| Fleet execution state | `agentic-ops-hub` |

Do not copy personal or plugin-installed skills into this command center. Pack
source stays in its owning repository; this repository stores lifecycle evidence
and routing metadata.
